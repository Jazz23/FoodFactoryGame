The 24 PlayMode failures are not caused by this change: 23 fail in SetUp because `Assets/Scenes/DevSite.unity` "has not been
added to the active build profile" (the same build-list state as the EditMode failure; `ProjectSettings` is unchanged), and the

`KitchenSessionTests.RecipeChooserAndKitchenCounterWorkThroughTheirScreens` and `AnEmployeeWorksTheCounterForABatchAndLeaves`,
the employee and oven tests in `ScreenOpeningTests`, `HiringSessionTests`, `RestaurantBuildingSessionTests` (register staffing),
and `CompetitorCustomerTests` (fixed to pick the bread menu item now that the menu has eleven).

Changed tests (fixtures, not gameplay): `RestaurantFurnishingTests.AmbienceIsOne…` stocks its register, since customers now
choose only stocked dishes; tests that loaded the retired `SellBread`/`Dough5` assets read the same IDs from `FoodBalance`;
`SessionAuthoringTests` expects the kitchen content in the scene lists; one oven idle-text expectation now reads "switch it on to
start".

## What the new tests cover

- Domain (`KitchenTests`): automatic keeps first-ready-by-ID; a chosen recipe is the only one started and a running batch keeps
  its recipe; refused choices (`forbidden`, `invalid-recipe` for another kind, a menu item or an unknown ID, `not-placed`) set
  nothing; a replay changes nothing; a worker-bound station starts nothing unworked, refuses a manual start (`unstaffed`), pauses
  when left and resumes; a mixer cannot be staffed (`not-a-register`); the setting survives a save; a v19 row loads on automatic;
  customers ignore a restaurant with nothing in stock and choose only the stocked dish; a wealthy district ignores tier 1 food and
  buys tier 2.
- Authoring (`KitchenContentTests`): every recipe, menu item and supply registers as server content for items with definitions
  and icons; each of the ten new dishes is made by a recipe and on the menu with a tier; every supplied ingredient is used; each
  station is sold, has one collider within its footprint and the right controls; buffers fit the widest recipe.
- PlayMode: the mixer screen offers Automatic plus four recipes and the choice replicates; the counter makes nothing unworked,
  makes a patty once the host works it through **Work this counter**, and is left when the host walks 12 m away, after which the
  batch stays paused; an employee's Work at counter task (built in the task panel) works the counter, makes a patty, and leaves it
  when stopped.
