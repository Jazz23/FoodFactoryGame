# Verification: world generator v2 (2026-09-28)

Decision: [0027](../decisions/0027-world-generator-v2-land-river-roads.md). Editor `6000.5.9f1`, Blender 5.2.2 LTS (MCP),
Windows, one Editor instance owned by the implementer. All stateful checks used temporary directories (tests) or the session
scratch directory (running hosts); no application save was opened or modified.

## Compilation and console

After each C# change: compile through MCP, then console errors. Final state: no compile errors; only the pre-existing
warnings (obsolete `FindObjectsSortMode`, `cursorColor`/`selectionColor`, FishNet Mirror upgrader). One compile error during
development (a tuple deconstruction arity in the validator) was fixed. The only console error in the running host came from
the MCP capture tool refusing a `..` save path (a tool call, not the game).

  float sampler within 1.1 cm).

  for byte with the same hash.
- `TheValidatorReportsBrokenLandRiversCrossingsJunctionsAndTrees`: missing rail/road bridges, missing or moved level
  crossing, uncontrolled junction, wrong elevation, trees in a house or the river, a house in the river, missing terrain.
- `WorldArtAuthoringTests` now also requires the water and bank materials and the 14 new pieces.

## Art

Blender ran `build_world_textures.py` (68 textures; the 56 originals came out byte-identical, so git shows only the 12 new
files) and `build_world_models.py` (47 objects). A Blender Eevee preview of the new pieces was checked before export (stop
sign lettering, crossbuck text, lamp colours, arm direction). `BuildWorldArt.cs` (through the MCP file-eval tool) reported
47 pieces, 50 materials, none unmapped.

## Running host

`Assets/Scenes/WorldGen.unity` in play mode; `SessionRoot.Configure` with an isolated save under the session scratch
directory, seed `20260927`, then `Begin(Host)`. The presenter built 1,782 buildings (4,157 renderers, 2,041 colliders).
The stored layout read back from that `world.db` is generator v2, format 2, hash `6e12b0fd…b598`. From the player camera at the
dev site: 1,362 draw calls, 12 batches, 715k triangles, 3.3 ms CPU / 1.6 ms GPU per frame in the Editor.

Defects found in captures and fixed before these captures:

- Riverbank trees stood in the water: the generator kept trees 2 m past the nominal water width, but the drawn waterline
  lies about 5 m past it. Trees now keep 8 m clear.
- Level crossing panels spilled about 6 m onto the grass because whole ballast tiles were removed; the track is now tiled in
  the gaps between crossings and the panel spans exactly the road.
- Relief first read as flat (about +-8 m over 320 m lattices); raised twice to the values in 0027.
- The first render of a newly created capture camera drew only restaurant awnings; the next captures of the same scene were
  complete. Seen once and not reproduced; not attributed to this change.

## Not verified

Separate-process multiplayer (a remote client receiving the larger layout over real UDP), a player build, walking the
avatar over hills and bridges (colliders exist but no walk was driven), seeds other than 20260927 in the running game, the
visual look at night, and any visual acceptance by the owner. No independent review has been done.
